# DSA Placement-Ready — Top 250

**Goal:** Placement coding rounds + technical interviews  
**Target:** Strong DSA foundation with high-value problems rather than solving 500 problems blindly.

## How to Use This List

- Learn the pattern before solving the problems.
- Solve Easy problems first, then Medium.
- Use Hard problems selectively after the core pattern is clear.
- A problem counts as **Done** only when you can:
  - identify the pattern within about 5 minutes
  - explain the approach
  - code without copying
  - state time and space complexity
  - handle edge cases
  - solve it again after a few days

## Recommended Pace

**3–5 quality problems/day** is better than rushing through 8 problems/day.

For each problem:

1. Try independently for 20–30 minutes.
2. Identify the pattern.
3. Study the solution only if stuck.
4. Code it yourself.
5. Record time + space complexity.
6. Re-solve after 2–7 days.
7. Mark it complete only when you can reproduce the approach.

---

# Final Goal

Do not aim to say:

> "I solved 250 LeetCode problems."

Aim to say:

> "When I see an unfamiliar problem, I can identify the likely pattern and build the solution myself."

That is the real goal of placement-ready DSA.
